Admin design prototypes

Five treatments of the same admin: authoring, drafts and publishing, attachments and the PDF lifecycle, hierarchical collections, and bulk operations.

  1. Tri-Pane
    Filter rail, sortable table, and a persistent inspector side by side.
  2. Ledger
    A single reading column with two-line bibliographic rows; editing opens in a sheet.
  3. Split Editor
    List grouped by source next to a tabbed editor with Fields, Publication, and Attachment.
  4. Grid Console
    A dense grid with every column visible and a bottom drawer for editing.
  5. Manuscript
    A narrow finder feeds a document-style form with publish controls alongside.

Static HTML, CSS, and vanilla JS over a shared in-memory model persisted for the session. Item types, field sets, creator roles, source connections, hierarchical collections, drafts/publishing, and the independent PDF lifecycle mirror the real schema. Changes made in one page are visible in the others; each page has a reset control.
