# Evidence Library Language

## Citations

### Library citation

A directed link from one published record to another record in the same Evidence Library. "Cited by" is the reverse view of the same link, not a separately stored list.

### Source citation metric

A count reported for a record by a named external source at a recorded time. It can include works outside the Evidence Library and must never be combined with library citations.

### Citation measure

The single citation dataset selected for a statistic: either library citations or one source citation metric. Each result names its measure so readers know what was counted.
